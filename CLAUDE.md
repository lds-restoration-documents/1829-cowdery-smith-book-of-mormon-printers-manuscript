## Files
`book-of-mormon-printers-manuscript-pages/page-NNN.md` (page number = image position in the manifest, 3 digits) are the source of truth; combined files are built by `tools/make_outputs.py` (layers: all-layers, first-inscription, scribal-corrections, compositor-marks, 1837-emendations; cumulative, `@later` only in all-layers; definitions in `tools/compile.py`). Rules: `tools/transcription-spec.md`, `tools/proofread-spec.md`; pipeline: `tools/README.md`.

## Rules (learned in the POC)
- Write the letters the scribe wrote. The main failure was **silently modernising spelling** (~100 words per 20 pages); the second was reading from memory of the printed text (inventing words) and omitting struck words. A glossary in the prompt did not help; the post-check does (`check_spelling.py`).
- Never transcribe without viewing the bands. If the image tool fails, stop and report; never write a page from memory (this happened once in the POC and the pages were discarded).
- `[...]` only where a letter or word is lost at a torn edge; if the next line's start completes the word (sp / ake) the mark is wrong and was removed (page 6). Output layers: see `tools/compile.py` docstring (old `base` was a hybrid of strikes plus insertions; do not reintroduce it).
- Layers: base text vs later-layer marks tagged `@1837` (darker-ink emendations), `@1830` (compositor's changes to words) or `@later` (unsure). Added punctuation and pilcrows (pilot, best-effort) are tagged by ink: `{,}@pencil` / `{,}@ink`; capitals traced over are not transcribed. The JSP online transcript holds the original inscription only.
- **Never show JSP to a transcriber.** Use it only afterwards (compare_reference.py) to find disagreements for human review, and check its reuse terms before publishing anything derived from it.
- Agent prompts come from `tools/agent-prompt.md`, which enforces concise output (no narration, one-line final reply); do not assume the session's output style reaches subagents.
- Opus for first-pass transcription; one fresh agent per page; blind second read for the top-signal pages (`page_signals.py`) plus a ~10% random sample. Do not use the draft-then-check pattern (an Opus checker over a Sonnet draft cost as much as a full read and was less accurate on emended pages).
- Second reads: batch 1 (pages 7, 8, 11, 13) was the calibration sample; for the rest, pick the global top 20 by `page_signals.py` plus ~10% random once all pages exist, not per batch. Reconcile with `tools/wdiff.py` and check each difference against the image (first-pass errors found: reading from the printed text, e.g. a plural added; misread folio numbers, so crop them).
- **At most 3 subagents at once**, one page per agent, run in waves of 3 (batches of 9 pages). Details: `tools/README.md`, Production run.
- Run-to-run noise on a page is about +-6 words per 600; do not over-read small differences between two runs.
- Record model and review per page range in `transcription-notes.md`; do not claim a page was proofread when it was not.
- No images in tracked files. **Never `git commit` or `git push`**; the owner does. `README.md` is owner-edited: change it with small edits only.
