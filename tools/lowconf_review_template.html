Low-confidence readings
Each card is one manuscript line the agents could not settle. The red bar at the left of the image marks the estimated line (it can drift by part of a line; read the neighbouring words in the yellow text to find it). Click an image to open it full size. Pick what the manuscript says: keep the transcript as it is, take one of the agents' readings, or type your own. Write your own reading in plain letters as the scribe wrote them; for a struck word write ~~word~~, for an insertion above the line ^word^; you need not add @1837 tags (say in the note if the dark ink is a later hand). Use can't tell when the image does not settle it. Decisions save in this browser automatically; export when done and send the file back.
