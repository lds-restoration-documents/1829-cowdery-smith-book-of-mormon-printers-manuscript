# tools

Pipeline for the Printer's Manuscript transcription. The page files in `../book-of-mormon-printers-manuscript-pages/` are the source of truth; combined texts are generated from them. Python: `~/.venvs/lds-transcribe/bin/python` (pypdfium2, Pillow) for image work; everything else is standard library.

0. **Images** (once): `python3 tools/download_images.py` fetches the 468 page images listed on the Archive Viewer page into `source-images/` (sequential, 4-7 s pause, resumable; about 45 min). Already done 2026-11-05.
1. **Bands**: `~/.venvs/lds-transcribe/bin/python tools/prepare_bands.py --pages 6-9` (reads `source-images/`; page number = position in `source-images/manifest.tsv`, `--list` shows the mapping; `--pdf SCAN.pdf` for a PDF) -> `work/img/pNNN_B.jpg` (native resolution, 120 px overlap); `--clean` when done.
2. **Transcribe** (agents, Opus, one page each, prompt from `agent-prompt.md` with its concise-output rule): follow `transcription-spec.md`; output `book-of-mormon-printers-manuscript-pages/page-NNN.md`. Log tokens per page.
3. **Check**: `python tools/check_structure.py` (37 lines, folio comment, balanced marks) and `python tools/check_spelling.py book-of-mormon-printers-manuscript-pages/page-NNN.md` (flags standard spellings the scribe likely wrote differently; false alarms are common, check the image).
3b. **Line-start hyphen cleanup** (agents often miss the scribe's hyphen at the start of a continuation line; a count of 0 does not prove a miss: p85 and p90 are genuinely 0, p71 was missing 6+). Pipeline: (a) `python3 tools/flag_linestart_hyphens.py A-B --detail` lists lines that probably continue a broken word and have no hyphen in the file (over-flags on purpose; 389 lines on pages 5-94 as of batch 10); (b) `~/.venvs/lds-transcribe/bin/python tools/cut_margin_strips.py A-B` cuts left-margin strips (420 px wide, top and bottom half of each page) into `work/strips/sNNN_1.jpg`, `sNNN_2.jpg` (`--clean` when done); (c) a Sonnet agent (~9 pages each, waves of 3) views the strips and returns, per page, only the line numbers that begin with a hyphen, as `PAGE<TAB>2,11,12` rows; (d) `python3 tools/patch_linestart_hyphens.py --file RESULTS.tsv` (dry run) then `--apply`. The patch script only adds `-` to the given text lines (comment-only lines are not counted, same numbering as the flagger), is idempotent and rejects out-of-range lines. The line numbers must come from viewing the image; never patch from the flag list alone. Run on pages 5-94 on 2026-11-05 (agents return `line:letters`; before patching, keep a line only if the file already starts it with '-', the flagger flagged it, or the first 2 letters match the file's line start; the rest go to `work/hy/skipped.txt`). Run again on pages 95-468 on 2026-11-12 (Sonnet agents, 10 pages each, 3 at a time; results filtered with `tools/accept_hyphen_results.py`, then patched; about 220 hyphens added); spot checks of 10 pages by count and 3 line by line found no miss or false hyphen; the ruled pages 170, 238, 239, 300 were re-read by an Opus agent (one hyphen added, p300 line 28; a few lines stay unsure). Details in `transcription-notes.md`.
4. **Select pages for a second blind read**: `python tools/page_signals.py --top 20` (strikes + illegible + uncertain; predicted error well in the POC) plus a random ~10% sample. Proofread per `proofread-spec.md`.
4a. **Ink-color pass (done 2026-11-12; method and decisions in `transcription-notes.md`, work files in `work/ink/`, gitignored)**: one Opus agent per page measured the darkest-3% pixels of each strike/insertion/caret against the text ink on the same line (PIL only, no numpy; crop whole bands of about 800 px and find the line by its words, never single lines by formula); owner rule: DARK -> `@1837`, SAME -> untagged, PENCIL -> `@1830`, UNSURE -> `@later`; a light insertion beside a dark strike or caret is tagged `@1837` as its partner. All 28 DOUBTs, p72, p173, p399 and the last 13 `@later` marks were image-checked; no inline `@later` is left. Original plan: measure stroke color of every `@later` strike/insertion (418 marks on 160 pages, mostly bare strikes of 'that', 'the', 'they') and spot-check `@1837` tags against known scribal strikes, so undated marks can be assigned a layer or left `@later`. `@later` stays out of every clean layer if it is used again.
4b. **Reconcile a second read** (`~/.venvs/lds-transcribe/bin/python tools/reconcile.py PAGE...` lists lines whose letters differ, ignoring case, spacing, added punctuation and tag layer, and writes one stacked line-crop image per page to `work/recon/`; bands for the blind reads are cut with `prepare_bands.py --pages ... --out work/proof-bands`; the 2026-11-07/12 run read 80 pages, see `transcription-notes.md` section 3; crops drift up to a line on short pages, so confirm the words in the crop before editing; hyphen rule: add a line-start or line-end hyphen on a word fragment when only one read has it). Older method: `python3 tools/wdiff.py book-of-mormon-printers-manuscript-pages/page-NNN.md work/proof/page-NNN.md` lists word-level disagreements (A = first read, B = blind second read); resolve each against the image, per `proofread-spec.md`. Batch 1 result (pages 7, 8, 11, 13): ~5 differences per 600 words, 4 real first-pass errors in 4 pages. **Settling the differences at scale (2026-11-12)**: `python3 work/settle/build.py` (list of differing lines, case/punctuation-only noise dropped, edit its page list), then one Opus agent per chunk of 12-18 lines with `work/settle/prompt.txt` (image first, then compare, verdicts to `out-NN.tsv`; 3 agents at a time), then apply the verdicts with `work/settle/sub.py` (head-of-line anchors; lines with mid-line comments need a direct replace) and regenerate outputs.5. **Score/review against JSP** (optional, after transcribing; never feed JSP to a transcriber): `python tools/compare_reference.py --ref work/jsp.txt --dir book-of-mormon-printers-manuscript-pages --map 10:5 --out work/diff.txt`.
6. **Combine**: `python3 tools/make_outputs.py` writes the 15 layered files to the repo root (`printers-manuscript-all-layers`, `-first-inscription`, `-scribal-corrections`, `-compositor-marks`, `-1837-emendations`; each as .md and .txt, clean layers also `-sparse.txt`), checks that clean files have no leftover markup, and writes `work/outputs-report.txt`. The .md files start with YAML frontmatter (title, scribes, date, layer, layer_description, contents, source_scan, transcription_method, status, repository, version; version = build date plus the hash of the last commit touching the page files, `+dirty` while page edits are uncommitted, so regenerate after committing); the .txt files carry a single `# title, layer (AI draft, no full human proofread) - repository URL` (sparse files: `(sparse, AI draft, no full human proofread)`) line instead (bare-overwrite warnings). Layers are cumulative; `@later` is applied nowhere except the legacy `--layer everything`. Single files: `python3 tools/compile.py --layer first|scribal|compositor|1837|full [--format md|txt] [--sparse] --out FILE` (legacy `base` = first, `emended` = everything). Sparse = the title page text (page 1, down to 'judgment seat of Christ'; byline and copyright entry left out; added 2026-11-20) and pages 5 to the end of Moroni on page 467, no page markers, a blank line between pages, line-broken words NOT joined (decided 2026-11-19: the hyphens are not reliable enough to join on; the scribe's line-start hyphens stay; `rejoin()` in `compile.py` is now unused). Non-sparse files already had a blank line between pages. Ink punctuation is assigned to the compositor layer because it rarely coincides with `@1837` words (evidence in `transcription-notes.md`).

Notes: `extract_reference.py` turns the JSP PDF into `work/jsp.txt`; `../docs/open-questions.md` lists next steps; `scribe-forms.tsv` lists standard->scribe spellings for the checker (extend as pages are verified). POC evidence for these choices is in `../docs/poc-findings.md`.

## Production run (decided in the 2026-11-05 pilot)
- **Agents:** Opus (`model: opus`), one fresh agent per page, prompt from `agent-prompt.md` (view each band once, one Write call, marks on). At most **3 agents at once**; start the next wave when the previous 3 have reported. Batches of 9 pages (3 waves).
- **Helper:** `python3 tools/run_batch.py prepare A-B` (skips existing pages, cuts bands, prints the waves of 3), then after the agents: `check A-B [--detail]` (one line per page), `clean`, `note "text"`. It does not launch agents. Run `clean` only after all 3 agents of the last wave have reported (cleaning early removed bands while page 372's agent was finishing, batch 44).
- **Per batch:** `prepare_bands.py --pages A-B` (default 900 px bands; 4 vs 5 bands made no cost difference: ~50k tokens/page) -> 3 waves writing `book-of-mormon-printers-manuscript-pages/page-NNN.md` -> `check_structure.py` + `check_spelling.py` (flags are often false alarms; check the image only for flagged lines) -> `prepare_bands.py --clean` -> log model, token counts and any failures in `transcription-notes.md` section 3. Skip pages whose file exists. Never fix a page from memory; re-run the agent or check the image.
- **Tags:** words: `~~ ~~`, `^ ^`, later layer `@1837`/`@1830`/`@later`; added punctuation/pilcrows by ink: `{,}@pencil`, `{,}@ink` (best-effort layer; capitals traced over are not transcribed). `compile.py --punct none|pencil|ink|all`. Counts of punctuation marks are not accuracy figures.
- **Known quirks:** many pages have 38-39 lines (the structure check only warns); an agent once wrote a flourish as `~~~` (fix by hand to a comment); `@1837` tagging of faint pages is inconsistent, so the second read focuses on words.
- Pilot outputs in `work/pilot-4band/`, `pilot-5band/`, `pilot-main/`, `pilot-rerun/` use older tags (`@1830` on punctuation); treat as evidence only, never copy into the pages folder.
