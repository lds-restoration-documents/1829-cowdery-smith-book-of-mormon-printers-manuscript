# tools

Pipeline for the Printer's Manuscript transcription. The page files in `../book-of-mormon-printers-manuscript-pages/` are the source of truth; combined texts are generated from them. Python: `~/.venvs/lds-transcribe/bin/python` (pypdfium2, Pillow) for image work; everything else is standard library.

0. **Images** (once): `python3 tools/download_images.py` fetches the 468 page images listed on the Archive Viewer page into `source-images/` (sequential, 4-7 s pause, resumable; about 45 min). Already done 2026-11-05.
1. **Bands**: `~/.venvs/lds-transcribe/bin/python tools/prepare_bands.py --pages 6-9` (reads `source-images/`; page number = position in `source-images/manifest.tsv`, `--list` shows the mapping; `--pdf SCAN.pdf` for a PDF) -> `work/img/pNNN_B.jpg` (native resolution, 120 px overlap); `--clean` when done.
2. **Transcribe** (agents, Opus, one page each, prompt from `agent-prompt.md` with its concise-output rule): follow `transcription-spec.md`; output `book-of-mormon-printers-manuscript-pages/page-NNN.md`. Log tokens per page.
3. **Check**: `python tools/check_structure.py` (37 lines, folio comment, balanced marks) and `python tools/check_spelling.py book-of-mormon-printers-manuscript-pages/page-NNN.md` (flags standard spellings the scribe likely wrote differently; false alarms are common, check the image).
3b. **Line-start hyphen cleanup** (agents often miss the scribe's hyphen at the start of a continuation line; a count of 0 does not prove a miss: p85 and p90 are genuinely 0, p71 was missing 6+). Pipeline: (a) `python3 tools/flag_linestart_hyphens.py A-B --detail` lists lines that probably continue a broken word and have no hyphen in the file (over-flags on purpose; 389 lines on pages 5-94 as of batch 10); (b) `~/.venvs/lds-transcribe/bin/python tools/cut_margin_strips.py A-B` cuts left-margin strips (420 px wide, top and bottom half of each page) into `work/strips/sNNN_1.jpg`, `sNNN_2.jpg` (`--clean` when done); (c) a Sonnet agent (~9 pages each, waves of 3) views the strips and returns, per page, only the line numbers that begin with a hyphen, as `PAGE<TAB>2,11,12` rows; (d) `python3 tools/patch_linestart_hyphens.py --file RESULTS.tsv` (dry run) then `--apply`. The patch script only adds `-` to the given text lines (comment-only lines are not counted, same numbering as the flagger), is idempotent and rejects out-of-range lines. The line numbers must come from viewing the image; never patch from the flag list alone. Run on pages 5-94 on 2026-11-05 (agents return `line:letters`; before patching, keep a line only if the file already starts it with '-', the flagger flagged it, or the first 2 letters match the file's line start; the rest go to `work/hy/skipped.txt`). Not yet run on pages 95-158. Details in `transcription-notes.md`.
4. **Select pages for a second blind read**: `python tools/page_signals.py --top 20` (strikes + illegible + uncertain; predicted error well in the POC) plus a random ~10% sample. Proofread per `proofread-spec.md`.
4a. **Ink-color pass (planned, with the second read over all pages)**: measure stroke color of every `@later` strike/insertion (418 marks on 160 pages, mostly bare strikes of 'that', 'the', 'they') and spot-check `@1837` tags against known scribal strikes, so undated marks can be assigned a layer or left `@later`. Until then `@later` stays out of every clean layer.
4b. **Reconcile a second read**: `python3 tools/wdiff.py book-of-mormon-printers-manuscript-pages/page-NNN.md work/proof/page-NNN.md` lists word-level disagreements (A = first read, B = blind second read); resolve each against the image, per `proofread-spec.md`. Batch 1 result (pages 7, 8, 11, 13): ~5 differences per 600 words, 4 real first-pass errors in 4 pages.
5. **Score/review against JSP** (optional, after transcribing; never feed JSP to a transcriber): `python tools/compare_reference.py --ref work/jsp.txt --dir book-of-mormon-printers-manuscript-pages --map 10:5 --out work/diff.txt`.
6. **Combine**: `python3 tools/make_outputs.py` writes the 14 layered files to the repo root (`printers-manuscript-all-layers`, `-first-inscription`, `-scribal-corrections`, `-compositor-marks`, `-1837-emendations`; each as .md and .txt, clean layers also `-sparse.txt`), checks that clean files have no leftover markup, and writes `work/outputs-report.txt`. The .md files start with YAML frontmatter (title, scribes, date, layer, layer_description, contents, source_scan, transcription_method, status, repository, version; version = build date plus the hash of the last commit touching the page files, `+dirty` while page edits are uncommitted, so regenerate after committing); the .txt files carry a single `# title, layer (unreviewed AI draft) - repository URL` (sparse files: `(sparse, unreviewed AI draft)`) line instead (sparse joins, bare-overwrite warnings). Layers are cumulative; `@later` is applied nowhere except the legacy `--layer everything`. Single files: `python3 tools/compile.py --layer first|scribal|compositor|1837|full [--format md|txt] [--sparse] --out FILE` (legacy `base` = first, `emended` = everything). Sparse = pages 5 to the end of Moroni on page 467, no page markers, line-broken words joined (line-start hyphen certain; line-end hyphen and vocabulary tests are heuristic, listed in the report; 6 lines still start with `- ` from the page files). Ink punctuation is assigned to the compositor layer because it rarely coincides with `@1837` words (evidence in `transcription-notes.md`).

Notes: `extract_reference.py` turns the JSP PDF into `work/jsp.txt`; `../docs/open-questions.md` lists next steps; `scribe-forms.tsv` lists standard->scribe spellings for the checker (extend as pages are verified). POC evidence for these choices is in `../docs/poc-findings.md`.

## Production run (decided in the 2026-11-05 pilot)
- **Agents:** Opus (`model: opus`), one fresh agent per page, prompt from `agent-prompt.md` (view each band once, one Write call, marks on). At most **3 agents at once**; start the next wave when the previous 3 have reported. Batches of 9 pages (3 waves).
- **Helper:** `python3 tools/run_batch.py prepare A-B` (skips existing pages, cuts bands, prints the waves of 3), then after the agents: `check A-B [--detail]` (one line per page), `clean`, `note "text"`. It does not launch agents. Run `clean` only after all 3 agents of the last wave have reported (cleaning early removed bands while page 372's agent was finishing, batch 44).
- **Per batch:** `prepare_bands.py --pages A-B` (default 900 px bands; 4 vs 5 bands made no cost difference: ~50k tokens/page) -> 3 waves writing `book-of-mormon-printers-manuscript-pages/page-NNN.md` -> `check_structure.py` + `check_spelling.py` (flags are often false alarms; check the image only for flagged lines) -> `prepare_bands.py --clean` -> log model, token counts and any failures in `transcription-notes.md` section 3. Skip pages whose file exists. Never fix a page from memory; re-run the agent or check the image.
- **Tags:** words: `~~ ~~`, `^ ^`, later layer `@1837`/`@1830`/`@later`; added punctuation/pilcrows by ink: `{,}@pencil`, `{,}@ink` (best-effort layer; capitals traced over are not transcribed). `compile.py --punct none|pencil|ink|all`. Counts of punctuation marks are not accuracy figures.
- **Known quirks:** many pages have 38-39 lines (the structure check only warns); an agent once wrote a flourish as `~~~` (fix by hand to a comment); `@1837` tagging of faint pages is inconsistent, so the second read focuses on words.
- Pilot outputs in `work/pilot-4band/`, `pilot-5band/`, `pilot-main/`, `pilot-rerun/` use older tags (`@1830` on punctuation); treat as evidence only, never copy into the pages folder.
